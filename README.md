# Amazie: AI Commerce Assistant

A prototype AI chatbot for Amaze App
currently deploy on Cloudflare page https://amazie.amazebiz.com

## Current architech
1. Gemini flash for LLM
2. Vite (TSX) + tailwind for style
3. Product from Amaze (Lotus's store) store as an object within data.ts file
4. Frontend deploy on Cloudflare page

## Pre-requisite
1. Gemini API credential
- expose via local env

## How to use

1. Install first
- npm install

2. Run dev server
- npm run dev

3. Run build script via
- npm run build
